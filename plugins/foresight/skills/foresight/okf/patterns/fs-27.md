# FS-27 · Existing primitive or house pattern bypassed

New code hand-rolls something the codebase already provides or mandates: the shared form and form-field components, searchable select and async-select pickers, dnd-kit, the shared modal's props, the global error-toast opt-out, the shared hours formatter, the shared KPI tile, the preferences store, the outbox for external I/O, the settings config helper, the e2e driver location, an existing WebSocket bridge. It works in isolation but reintroduces solved bugs and inconsistency, and is flagged in review.

**Triggers**
- adding a form, picker, drag interaction, modal, stat row, settings card or displayed number
- new external I/O, settings block, per-user toggle storage or realtime delivery
- creating an e2e driver/helper, or a component file in a feature that has a barrel
- writing a new management command/script for a data check; a new model or report layout next to an established precedent
- writing a fresh store upload/release script (Play Publisher, ASC API) while one already exists in the repo's scripts/
- a design system that offers both a native-popup Select and a fully custom popup, used for a fixed enum whose design shows a styled panel
- a new GitHub Actions workflow that pushes or opens PRs; a new true-negative fixture in a set whose siblings follow an unvalidated convention

**Guards**
- Search the shared UI and shared utility modules, sibling features and the project's agent conventions file (CLAUDE.md) for an existing primitive before writing a new one
- Copy the pattern from the nearest sibling usage and route numbers through the shared formatter
- Add barrel exports and driver methods in the same commit as the new file
- Reuse and extend the committed release scripts instead of hand-rolling API calls
- Open the popup when pixel-matching and use the fully custom popup component for fixed enums
- Copy the permissions: block and PR-creation action from sibling workflows; match the non-obvious fields of sibling fixtures, not only the literal expected value
