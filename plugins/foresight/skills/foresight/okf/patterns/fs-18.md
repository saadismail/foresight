# FS-18 · Shell and CLI step semantics assumed

Multi-step shell work assumes semantics that don't hold: persisted cwd, bash word-splitting under zsh, GNU vs BSD tools, pipes that buffer until exit, nohup without stdin redirect, SSH jobs not detached, one stdin shared by bash -s commands, wrapper exit codes that don't propagate, git add silently staging nothing. The step 'succeeds' or appears hung and the agent proceeds on a false outcome.

**Triggers**
- chained cd/source && command, or relative paths after a background/long-running command
- an unquoted $VAR holding several paths in zsh; multi-line awk -v; timeout on macOS
- a long remote job over SSH/gcloud, or ssh ... | bash -s with several docker exec -T calls
- judging success from a wrapper's exit code, or git add with a long explicit path list
- vite/vitest started in the background or piped through grep
- a manage.py shell -c / < script gated on sys.argv; git add -A inside a worktree; pkill -f whose pattern is in its own argv; bash-4 syntax under macOS bash 3.2; a first command that searches from / instead of the given path
- a background release/build step (gradle, xcodebuild, altool, Play upload) judged by its task notification or exit code; a script writing into a computed per-run output directory; build commands run with relative paths late in a long session
- a test harness judged through `cmd | tail -N`, or a pass/fail taken from grep -c on a command's output; file tools given relative paths after Bash ran inside a worktree
- a command composed as timeout N ... on a macOS host (recurs: zsh has no GNU timeout)
- a GitHub Actions run: step pipes a test command into tee/grep; a shell loop over gh/git commands that prints one summary line; a python -c one-liner with quoted f-strings inside a double-quoted shell arg; a pg_restore/pg_dump flag not smoke-tested; a django.setup() one-liner run from an arbitrary cwd; git checkout -- as a mutation-test revert before any commit exists
- the task prompt already gives the absolute path of the skill/context file, yet the first command is a find / or a relative path (the agent's skills directory) inside a per-run sandbox whose cwd differs from the usual checkout (recurs across parallel runs of one task, each burning the full tool timeout)
- a command line interpolates a string variable holding several flags ($SSHO, $OPTS) and runs under zsh, the macOS default shell
- an unquoted *, ? or [..] in a zsh command (grep --include=*.py, ls dir/*, a glob over a maybe-empty dir): zsh NOMATCH aborts the whole command instead of passing the literal through (recurs: 5x in one session)
- a quoted glob handed to a program that opens paths literally (node fs, a custom script); a verification probe that regex-scrapes a port out of free-form argv/log text
- a regex filter (git log --grep, grep -E) using \b or another PCRE-only escape; a reset --soft, squash or split onto a base branch tip that keeps moving; a desktop-managed shared service relaunched with open -a
- supervisor code classifies a child process's run (stopped, failed, done) from its exit code after signalling it

**Guards**
- Use absolute paths and git -C <worktree>; never rely on the persisted cwd
- Verify each step's effect, not its exit code: git diff --cached --stat, git log -1, grep remote logs for ERROR
- Detach remote jobs with nohup/setsid plus a log file and poll; run background vite/vitest with </dev/null and --pool=forks --maxWorkers=1
- Use ${=VAR} or arrays in zsh, and check command -v and the platform before relying on GNU-only tools
- Gate apply flags on env vars and start prod scripts from one saved template; stage explicit paths; use bracketed pgrep patterns; read a task's given path directly and bound any search with a timeout
- In build wrappers propagate child exit codes (set -e -o pipefail, PIPESTATUS), grep the output tail for BUILD FAILED/ERROR, and confirm uploads through the store API (list builds); mkdir -p output dirs before writing; run platform builds from an explicit absolute directory and make background-wait patterns match any error/failed line
- Use set -o pipefail or PIPESTATUS[0] before trusting a piped result, and re-run a suspicious 'zero' without the pipe; pass absolute paths to every file tool; check git diff --cached --stat for build/output dirs before committing
- On macOS never prefix with timeout; use the tool's own limit (ssh -o ConnectTimeout, jest --testTimeout) or a documented wrapper
- Add set -o pipefail explicitly to piped CI run: steps and prove it by making the test fail once; print and re-verify each loop iteration's real result (gh pr view --json state); put throwaway scripts in a .py file; check unfamiliar flags with --help and verify row counts after a restore; save a commit or patch before reverting a mutation
- Make the first action a Read/Skill call on the exact absolute path in the prompt; run pwd before any relative path; if discovery is unavoidable, scope find to the project or scratch dir with -maxdepth
- Hold multi-flag options in an array (opts=(-o A=b -o C=d)) and pass them to ssh with quoted array expansion of all elements, or inline them; never an unquoted string variable
- Quote every glob passed as an argument ('--include=*.py'), prefer rg -g, and use the (N) qualifier or setopt nullglob before listing maybe-empty paths
- Never type `timeout` on this host: use the Bash tool's own timeout parameter or the runner's --timeout, and check ${pipestatus} rather than $? after a pipe
- Have servers print one machine-readable line (LISTENING <port>) or pass the port explicitly; glob inside scripts rather than relying on shell expansion
- Prove a search filter on a known-positive input before trusting a no-match (-P or -w instead of \b in ERE); split or squash against git merge-base HEAD origin/<base> and check git diff origin/<base>...HEAD is unchanged; after relaunching a shared local service poll its health (docker info, pg_isready) and kill leftover helper PIDs if the relaunch did nothing
- Record the stop reason before signalling a child process and classify the outcome from that record; test children that exit 0 and non-zero after SIGINT
