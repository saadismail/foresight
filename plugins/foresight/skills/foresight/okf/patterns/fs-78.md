# FS-78 · Manual RTL flip stacked on a layer that already auto-mirrors

Under I18nManager RTL, Yoga mirrors left/right and absolute positions, React Navigation's native header back button and some icon sets mirror themselves, and custom icon components do not. Code adds scaleX(-1) or I18nManager.isRTL left/right swaps on top of an auto-mirroring layer, which double-flips back to the wrong direction; a fix that then removes the flip everywhere breaks the path that doesn't mirror. Each render path behaves differently and only an RTL device check shows it.

**Triggers**
- a style checks I18nManager.isRTL to swap left/right, borderLeft/borderRight or margins
- a directional icon (chevron, arrow, back) wrapped in scaleX(-1) or an rtlFlip helper
- the same glyph rendered through a native navigation header and through a custom shared icon component

**Guards**
- Use logical start/end properties (marginStart, borderStartWidth, start) instead of manual isRTL swaps
- Before adding a manual flip, check on device in RTL whether that exact render path already mirrors
- When fixing one RTL direction bug, grep every render path of that icon and verify each one on device
