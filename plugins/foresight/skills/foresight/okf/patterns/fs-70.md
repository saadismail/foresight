# FS-70 · Mobile behavior verified on one OS or only on the Simulator

A React Native change is checked on one platform (often the Android emulator or one iPhone simulator) and reported fixed for both, but iOS and Android diverge: iOS presents only one Modal at a time, Android's LinearGradient ignores border radius and overflow set on itself, contentInset exists only on iOS, a Maestro flow hardcodes one platform's appId. The Simulator also differs from devices: native store sheets don't render, 'Connect Hardware Keyboard' suppresses the soft keyboard, and automated text injection drops characters. The user on the other platform or on a real device finds it.

**Triggers**
- a layout, modal/sheet, gradient, keyboard or native-SDK change about to be reported done with screenshots from one platform
- a component opens a second Modal (image picker, sheet) while another Modal is visible
- a shared Maestro/e2e flow file with a literal appId or a platform-specific selector
- the user reports a control 'does nothing' that works on the developer's simulator
- verification depends on the soft keyboard or on typing long strings into the iOS Simulator
- keyboard-avoidance fixes look identically broken across rebuilds on the iOS Simulator

**Guards**
- Screenshot-verify every RN UI fix on both iOS and Android (and a real device for native sheets, gradients and keyboard) or state explicitly which platform was checked
- Never stack RN Modals: close the first or render the second inside it, and test nested modal/sheet flows on iOS
- Parameterize appId per platform in Maestro flows and smoke-run each new flow on both platforms before using it as a RED/GREEN gate
- On a repeated 'not working' report, gather device logs, viewport width and platform capability before reasserting that it works
- Before keyboard tests on the iOS Simulator turn off Connect Hardware Keyboard; for text-heavy input use a real device or chunked typing with read-back
- Make 'Connect Hardware Keyboard off' step 0 of any keyboard bug checklist; if keyboardDidShow never fires, check the setting before changing code
