# FS-104 · Smoke or verification write run against a live production target

A smoke test or verification step performs a real write (deploy, publish, send) against a live production site or tenant because it is the closest real target. The write has side effects beyond the test itself, such as moving a public 'latest' alias or notifying users, so real visitors see test content. Read-only probes would not have changed anything; the side effect is noticed only by a later sweep or a user.

**Triggers**
- a smoke, canary or go-live check that deploys, publishes or sends against an existing live site, tenant or channel
- an operation that updates a shared pointer as a side effect (latest alias, default version, pinned release)

**Guards**
- Smoke-test writes against a dedicated throwaway target; use read-only probes on live targets
- Before any write on a live target list its side effects (aliases, pointers, notifications) and diff the public state before and after
