# FS-102 · Performance lever chosen or credited without profiling, mechanism check or a controlled quiet-host A/B

Speed-up work picks a lever from a plan's premise (backend cost dominates, per-worker servers cap width, CONN_MAX_AGE pools connections, prepare_threshold caches plans) without a per-component time breakdown or a check that the mechanism is actually active at runtime, then judges it from single-shot wall-clock runs on a host shared with other lanes (load average 20-142). Inert levers get credited, real ones look like regressions, and ms budgets asserted inside a parallel suite fail by load, not code.

**Triggers**
- a perf lane or brief assigns a lever to a layer (backend, DB driver, server count) before a per-test or per-request time breakdown exists
- a settings comment or plan claims a driver/runtime option speeds things up (CONN_MAX_AGE under ASGI/Daphne, psycopg prepare_threshold, statement cache)
- a before/after timing claim from one run each, on a machine where other agents, lanes or suites are running
- several parallel lanes each asked to prove a speed-up with wall-clock benches on the same host
- a test asserting a p95/ms budget that runs inside the default xdist/parallel suite or on shared CI hardware

**Guards**
- Profile one representative test or request first (API wall vs render/Vite vs setup, CPU per component at target width) and size the lever's ceiling before dispatching work on it
- Prove the lever's mechanism is live before crediting it: pg_stat_database.sessions before/after N requests for connection reuse, pg_prepared_statements and EXPLAIN planning time for plan caching, the resolved settings module for config levers
- Run A/B as interleaved pairs (ABBA/BAAB) from the same DB state under a host-wide bench lock, record load average per run, never run your own probes during a bench, and require the delta to exceed the spread of repeats
- Gate perf in the main suite on query counts or other load-independent measures; move wall-clock ms budgets behind a marker run serially on a quiet host
